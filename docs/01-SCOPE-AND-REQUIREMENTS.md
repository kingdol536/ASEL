## 3. 12주에 반드시 남겨야 할 산출물

1. **실행 가능한 코어**: 상태·행동·목표·제약·이벤트를 다루는 최소 공통 모델.
2. **단위 실험 세계**: 2D 관계 뷰 + headless 반복 실행.
3. **AI/정책 실행 통로**: 최소 하나의 실제 AI 연동 경로 및 기준선 알고리즘(비용이 발생할 때는 호출 횟수 제한). AI의 최종 역할 체계는 열어둔다.
4. **재구성 시나리오**: 구조나 역할·연결 변경이 단순 작업 할당과 구별되어 기록된다.
5. **평가 격리**: 내부 에이전트가 숨겨진 사실을 읽지 못하고 평가기는 결과와 정답에 접근한다.
6. **제한된 3D 통합 시험**: 상태를 재생하고 최소한의 3D 공간·충돌/점유 제약을 시험한다.
7. **증거 패키지**: 입력 설정·시드·테스트·실험 로그·보고서·실패 사례·시연.

`최소 하나의 실제 AI 연동 경로`는 다양한 역할을 고정하지 않고 AI 구성 실험의 기반을 마련하려는 구현 목표다. 네트워크·비용 제약으로 미완료 시 모의 정책으로 기능 검증하고 제한을 명시한다.

## 4. 12주 완료를 위협하는 범위 확대

**초기 제외:** 전 공정 고정밀 3D, 실물 공장 연동, 로봇의 복잡한 다관절 제어, 다중 물리 엔진 완성, 사이버 공격 재현, 강화학습 대규모 학습, 무제한 AI 에이전트 자동 생성, 모든 산업의 완전한 공통 온톨로지.

규모 확장을 승인하려면: (a) 핵심 가설에 필수, (b) 검증 조건 명확, (c) 기존 12주 게이트 유지가 가능해야 한다.

## 5. 비기능 요구사항

- **재현성:** 동일 설정·시드·버전으로 논리 상태/이벤트 재현 가능 범위를 문서화.
- **추적성:** 모든 구조 변경에는 요청 주체·사유·승인/거절·적용 결과 기록.
- **격리:** AI/정책의 허가된 관측과 평가기 비공개 정답을 분리.
- **모듈성:** 렌더링, 환경, 정책, 평가를 교체 가능한 계약으로 구분.
- **안전:** 불변조건 위반 행동을 적용 전에 거절. 통과가 현실 안전을 보장하지는 않음.
- **측정 가능성:** 실험 설정과 결과 파일을 자동으로 남길 수 있어야 함.

| 이슈 | 결정 시점 제안 | 필요한 증거 |
|---|---|---|

| 최종 포트폴리오 주평가 지표 | 첫 기준선 및 연구 질문 명료화 후 | 측정 가능성·타당성·반례 |
| 첫 산업 모델 세부 선택 | 1~2주 | 단순성·재구성 가능성·물리 제약 |
| 3D 엔진 확정 | 소형 렌더링/물리 프로토타입 후 | 상태 동기화·개발 비용·GPU 성능 |
| 두 번째 산업 환경 도입 시점 | 8주 게이트 | 코어 재사용/수정량 테스트 가능성 |

## 7. 변경 통제

- 각 변경은 요구사항 ID, 사유, 영향받는 문서, 실험·테스트에 미치는 영향, 상태를 기록.
- '미결정'을 '확정'으로 바꿀 때는 비교 또는 외부 제약 근거 필요.
- 새 연구 아이디어는 우선 **장기 확장 백로그**로 분류하고 12주 목표를 자동 수정하지 않는다.
