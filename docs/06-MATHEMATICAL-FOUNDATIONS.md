# 06. 수학적 모델·알고리즘 후보와 적용 조건

> 상태: **방법론 후보 모음**. 모든 이론을 동시에 구현하는 계획이 아님.

## 1. 연구에서 수학을 사용하는 방식

'현상 관찰 → 변수·제약 정의 → 반증 가능한 가설 → 기준선 선택 → 알고리즘 구현 → 비교 평가'를 반복한다. 특정 이론을 사용했다는 사실만으로 개선을 주장하지 않는다.

## 2. 공통 상태와 동적 시스템

시점 `t`의 시스템 구조를 `G_t=(V_t,E_t)`, 자원 및 작업 상태를 `x_t`, 운영 행동을 `a_t`, 구조 변경을 `r_t`, 환경 변동을 `w_t`로 둔다.

\[
x_{t+1}=f(x_t,G_t,a_t,r_t,w_t),\qquad G_{t+1}=g(G_t,r_t)
\]

이것은 범용 관계를 표현한 모형이며 실제 상태 전이의 의미는 환경마다 달라진다.

### 행동의 두 시간 척도

- **빠른 운영 제어:** 작업 할당·경로·자원 예약.
- **느린 구조 제어:** 셀 기능 변환·모듈 이동·연결 구조 변경.

구조 변경에 비용과 중단시간이 발생할 수 있으므로 두 정책을 동일한 빈도로 호출하면 비효율적일 수 있다.

## 3. 후보 이론 매핑

| 현상 | 수학·CS 기법 | 사용 조건 | 주의 |
|---|---|---|---|
| 구성 요소 의존 관계·모듈 경계 | 그래프, DSM, 그래프 분할 | 관계를 노드·간선으로 표현 가능 | 간선 가중치의 의미 명시 |
| 작업·설비 경합과 대기 | 이산 사건 시뮬레이션, 대기행렬 | 도착·서비스·자원 제한이 존재 | 단순 대기행렬 공식을 현실에 과적용 금지 |
| 자원 할당·선후관계 | CP-SAT, MILP, 휴리스틱 | 불연속 선택·제약이 명확 | 확장성/계산 시간 측정 |
| 불확실한 수요와 고장 | 확률 과정, 베이지안 추론 | 분포를 가정·추정할 수 있음 | 분포 이동·편향에 취약 |
| 목표 전환과 비용 충돌 | 다목적/강건 최적화 | 목표가 비교 가능한 경우 | 목적함수 가중치 임의 조작 금지 |
| 구조 재구성의 빈도·지연 | 제어 이론, MPC, hysteresis | 상태 피드백, 전환 비용 존재 | 안정성/전환 비용 별도 평가 |
| 부분 관측·순차 결정 | (PO)MDP, 옵션/계층형 제어 | 관측이 불완전하고 미래 행동에 영향 | 상태·보상 정의가 어려움 |
| 다중 AI 협력 | 분산 최적화, 게임 이론 | 주체 사이 정보·목표가 구분됨 | 통신비용·교착·중복 행동 |
| 정보 및 모델 정밀도 선택 | 정보 이론, 능동 관측, 가치정보(VOI) | 관측/정밀화에 비용 발생 | 정보량 증가가 유용성 증가와 같지 않음 |
| 허용 행동 보장 | 불변조건, 계약·형식 검증 | 특정 위반을 기계적으로 검사 가능 | 모델 바깥 현실의 안전을 보장하지 않음 |

## 4. 구조 변경의 간단한 목적함수(예시)

\[
J(\pi)=\mathbb E\sum_{t=0}^{T}
\left[C_{\mathrm{operation}}(t)+C_{\mathrm{delay}}(t)+C_{\mathrm{change}}(G_t,G_{t-1})+C_{\mathrm{risk}}(t)\right]
\]

- `π`는 관측에 따라 행동을 선택하는 정책.
- 각 항은 같은 단위(예: 비용)로 보정할 근거가 없다면 **합산해서 결론을 내리지 말고 다차원 결과를 함께 공개**한다.
- 안전처럼 절대 위반 불가한 조건은 비용 항으로만 처리하지 않고 제약으로 분리.

\[
\mathrm{subject\ to}\quad h_j(x_t,G_t,a_t,r_t)\leq 0\quad \forall j,t
\]

**최종 평가 목적함수는 아직 미결정**이다. 위 수식은 학습 및 구현을 위한 후보 구조다.

## 5. 병목 전이의 정량적 분석

시스템의 자원/제약별 유효 부하 또는 제한도를 `b_i(t)`로 정의한다. 단순한 후보는 `수요/가용 처리능력`이지만 구조에 따라 적절하지 않을 수 있다.

- 정책 도입 전후 가장 강한 제약이 어느 곳으로 이동하는가?
- 기존 제약의 완화량에 비해 새로운 조정·재구성 비용은 얼마나 증가하는가?
- 동일 조건을 재실험했을 때 병목 이동이 재현되는가?
- 조정 비용이 증가한 원인이 그 정책인지, 외생 수요 변화인지 구분 가능한가?

### 인과 평가의 최소 원칙

- 동일한 외부 수요/고장 시나리오에 여러 정책을 적용한다(대응 비교).
- 변경할 한 요소만 다르게 하는 절제 실험을 수행한다.
- 시스템 초기 상태·자원·시간 예산을 비교 가능하게 맞춘다.
- 정책 효과는 평균뿐 아니라 조건별 실패 사례를 분석한다.

## 6. 공진화 연쇄를 형식화하는 방법(후속 연구 후보)

`problem_t → intervention_t → changed constraints_{t+1} → adaptation_{t+1}`.

새로운 병목이 실제로 발생했는지 판별하기 위해 외부 요인(`w_t`)을 통제하는 실험군이 필요하다. 단순 버전업으로 효과를 정의하지 않는다.

## 7. 처음 구현할 수학적 핵심

1. **그래프 모델**: 구성요소·경로·의존 관계.
2. **이산 사건 모델**: 작업·대기·자원 사용·전환 지연.
3. **정확한 불변조건**: 자원 예약 및 허가되지 않은 행동 거절.
4. **단순 비교 정책**: 고정 구조, 반응형/탐욕 재구성, 전환 비용 고려 정책(잠정).
5. **실험 통계**: 대응 반복, 효과 크기, 불확실성 추정.

초기 12주 내 강화학습이나 대규모 다중 물리의 도입은 필수 요건이 아니다.

## 8. 개념 검증 예시

가령 공용 셀 하나를 피킹 또는 포장 역할로 변경할 수 있다고 하자. 변환에는 120초의 비가동 시간이 든다(**가상 값**). 순간 대기열만 보고 재구성하는 정책과 미래 작업량·전환 비용을 고려하는 정책의 실제 총비용을 비교한다.

- 통과 조건은 '반드시 후자가 우월함'이 아니라, **어떤 수요·전환 비용에서 결과가 뒤집히는지 재현 가능하게 보이는 것**.
- 해석 결과가 시뮬레이터의 가정에 좌우되면 민감도 분석과 한계 명시.

## 9. 필요한 학습의 우선순위

연구 질문과 코드 문제에 부딪혀 필요한 경우 순차 학습: Python 데이터 모델/테스트 → 그래프·이산 사건 → 제약 최적화 → 통계적 실험 → 제어·다목적 → 부분 관측·분산 정책 → 다중 물리.
