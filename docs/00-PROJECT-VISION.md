# 00. 프로젝트 비전과 연구 목표

> 상태: **핵심 방향 확정 / 산업 전망 및 범용성은 가설**

## 1. 문제의식

현재의 AX(AI Transformation)는 기존 프로세스에 AI 기능을 더하는 접근이 많다. 본 프로젝트는 다음의 후속 질문을 연구한다.

- 시스템이 **무엇을 처리하는가**뿐 아니라 **무엇으로 구성되고 어떻게 연결되는가**도 변경 대상이 될 수 있는가?
- 단기 최적화가 새로 만드는 병목·충돌·전환 비용을 어떻게 파악하고 다룰 수 있는가?
- 공장·물류·IT 시스템의 서로 다른 제약을 보존하면서 공통된 제어 인터페이스를 사용할 수 있는가?
- 전체를 항상 최대 정밀도로 분석하지 않고 상황에 따라 정보·모델 복잡성을 선택할 수 있는가?

## 2. 연구 비전

**Adaptive System Evolution Lab**: 목표·환경·구성요소·제약이 변화하는 가상 산업 시스템에서, AI 및 알고리즘이 운영과 구조의 변경을 제안·검증·수행하고 변화로 인한 새로운 문제를 관찰하는 실험 플랫폼.

### 단기 성공과 장기 연구의 구분

- **1차(12주)**: 설계한 메커니즘이 작은 실험 환경에서 **실제로 동작하고 재현 가능하게 평가**됨을 입증하는 독립 포트폴리오.
- **2차(추가 5~12개월)**: 3D·다중 물리·다중 산업 환경을 확장하고, 반복적인 병목 탐지 및 적응 메커니즘을 심화.
- 직무 지원과 외부 피드백은 별도 채용 전략과 병행. 연구의 성공을 취업 보장으로 표현하지 않는다.

## 3. 핵심 개념

### 3.1 구조 재구성(Reconfiguration)

설비/서비스의 배치, 작업 경로, 구성요소 연결, 역할 할당 또는 운영 규칙의 **명시적 변경**. 일상적인 작업 실행과 구별한다.

### 3.2 공진화(Co-evolution, 프로젝트의 작업 정의)

**환경의 제약 ↔ 시스템 구조 ↔ 운영·통제 정책**이 서로 영향을 주며 변하는 과정. 예시:

1. 기존 경로에서 작업 대기 증가.
2. 경로/작업 셀 재구성으로 대기 감소.
3. 변경 빈도 증가로 중단·조정 비용 발생.
4. 변경 억제 규칙 도입 후 급변 수요에 대한 반응 지연 발생 가능.
5. 변경 시점 결정 정책 개선 및 한계 측정.

위 연쇄는 **연구 가설의 예**이며, 실험하지 않고 발생했다고 주장하지 않는다. '개발 버전이 증가했다'는 사실은 공진화 증거가 아니다.

### 3.3 범용 메커니즘과 도메인 어댑터

공통 기능(상태 관측·행동 요청·제약 확인·결과 기록)과 도메인 속성(설비·작업·물리 조건)을 분리한다. **모든 산업에 보편 적용 가능하다는 주장은 하지 않는다**. 이식 범위는 다른 환경에서 시험한다.

### 3.4 복잡성의 선택적 활성화

전체 시스템을 평상시 낮은 세부 수준으로 관찰하다가, 이상·목표 전환 등의 조건에서 특정 부분 모델을 정밀화하고 원인을 추적할 가능성을 연구한다. 초기에는 개념과 최소 인터페이스만, 본격적 다중 물리 모델은 후속 연구.

## 4. 시스템 진화의 장기 가설(2028~2030)

- 단순 작업 자동화를 넘어 **시스템 구조 생성·재편**이 중요해질 가능성.
- AI 주체가 많아질수록 역할 간 조정, 권한, 정보 공유와 평가 문제가 병목이 될 가능성.
- 서로 다른 모델 간 가정·단위·시간 척도 불일치를 탐지하는 기술의 중요성 증가 가능성.
- 재난·내부 위협·사이버 공격 등 비정상 환경에서 안정성을 유지하도록 구조를 변경하는 방어적 복원력 연구 필요 가능성.

위 문장은 **전망/가설**이며 시장 규모·도입 시점을 실증한 사실로 쓰지 않는다.

## 5. 무엇이 프로젝트의 성과가 아닌가

- 장면이 보기 좋다는 이유만으로 디지털 트윈의 정확성이 입증된 것.
- 특정 가상 물류센터의 처리량만 향상시킨 것을 산업 범용성으로 주장하는 것.
- AI를 많이 호출하거나 에이전트 수를 늘린 것을 자동화 수준 향상으로 주장하는 것.
- 시뮬레이터 내부 정답을 AI가 이용한 결과를 자율적 추론으로 주장하는 것.
- 실험 전에 정한 한계·실패 사례를 숨긴 성능 주장.

## 6. 비전 평가를 위한 장기 질문

- 한 산업에서 검증한 제어 계약이 다른 산업에서 어떤 수정 없이 유지되는가?
- 최적화 정책은 어떤 조건에서 병목을 새로운 위치로 이동시키는가?
- 목적이 바뀌면 구조를 얼마나 재사용할 수 있고 무엇을 재검증해야 하는가?
- 시스템 일부를 격리·변경해도 필수 기능을 보장할 수 있는가?
