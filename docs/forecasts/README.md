# 예측 기록 (forecasts)

산업 문제를 **해결하기 전에** 예측을 적어 커밋·푸시로 고정한다. 실험 계획서 사전 등록(`experiments/plans/`)과 같은 원리다.
나중에 실제 산업 변화·실험 결과와 대조해, 예측이 맞았는지 틀렸는지를 그대로 기록한다.

## 규칙

1. 고정한 파일은 오탈자 외에는 고치지 않는다. 판단이 바뀌면 새 파일을 만들고 이전 파일을 링크한다.
2. 모든 문장은 **예측(가설)** 이다. 근거 수준(강함·중간·약함)을 단계마다 표시하고 숨기지 않는다.
3. 각 예측에는 나중에 대조할 관측(지지·반증 조건)을 함께 적는다.
4. 예측 기록은 12주 필수 범위를 바꾸지 않는다. 새 작업 후보는 `docs/01-SCOPE-AND-REQUIREMENTS.md` 의 장기 후보로 보낸다.
5. 근거 조사 작업본은 저장소 밖(Notion)에 둔다. 이 폴더에는 고정본만 둔다.
