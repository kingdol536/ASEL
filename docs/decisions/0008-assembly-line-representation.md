# 0008. 조립 라인(환경 B) 표현: 코어 확장 없이 기존 부품으로, 재고·유한 버퍼는 범위 밖

- 상태: **잠정** (2026-11-11)
- 관련: 티켓 #36(T4.0), #37(T4), 동결 커밋 `e935739`, 이식성 측정 방법

## 맥락

환경 B 는 공통 언어 v0 를 만들 때 이미 알려진 '설계 참고 환경'이다. 조립 라인의 일반적인 특징 중 무엇을 B 에 넣을지,
그리고 그것이 코어 확장을 요구하는지 판단해야 한다. **주의:** B 의 특징을 고르는 사람이 코어를 만든 사람과 같으므로,
"코어 변경이 필요 없는 특징만 골라" 이식성을 좋아 보이게 할 위험이 있다. 그래서 일반적 특징 목록을 먼저 적고, 넣지 않은 것과 이유를 함께 남긴다.

## 조립 라인의 일반적 특징과 판단

| 특징 | 필요한 표현 | 판단 |
|---|---|---|
| 하위 조립 병렬 → 합류 (프레임·모터 → 조립) | 다중 선행관계 DAG | **포함.** 코어가 이미 지원 (`Task.predecessors`), 설정만 필요 (`workload.flow`) |
| 제품 혼류 (A·B 제품, 경로가 다름) | 도착마다 흐름 선택 | **포함.** 공용 엔진(시나리오 스키마·흐름 어댑터)에 혼류 비율 추가 — 코어 변경 아님, 변경량으로 기록 |
| 제품 전환 셋업 시간 (프레스가 A↔B 바꿀 때 정지) | 셀 역할 전환 + 전환 시간 | **포함.** 기존 재구성 개념(결정 0005)을 그대로 쓴다: 프레스 역할 `press-A` ↔ `press-B`, `changeover_s` = 셋업 시간 |
| 부품 재고·BOM 수량 (부품 n 개가 모여야 조립) | 재고 상태, 소비·보충, 수량 불변조건 | **제외.** 코어 확장 필요 (새 상태·행동·불변조건). B 에서는 작업 묶음 1개 = 제품 1개로 단순화 |
| 유한 버퍼·막힘(blocking) | 공정 사이 저장 용량, 하류가 차면 상류 정지 | **제외.** 코어 확장 필요. 지금은 대기열 무한 가정 |
| 운반(AGV·컨베이어 이동 시간) | 이동 시간·운반 자원 | **제외.** 이동 모델 없음 (결정 0007 의 정적 3D 와 별개) |
| 불량·재작업 루프 | 순환 경로 | **제외.** 공정 흐름은 순환 불가(DAG) |

## 선택

B 는 **합류 DAG + 제품 혼류 + 셋업(재구성)** 으로 만든다. 코어는 고치지 않는 것이 목표지만, 필요하면 고치고 변경량과 이유를 그대로 보고한다.
제외한 4가지는 B 가 '조립 라인 전체'를 대표하지 않는다는 한계로 보고서에 적고, 장기 후보(R-16)로 올린다.

## 대안 포기 비용

- 재고·버퍼가 없어 막힘(blocking)으로 생기는 병목 이동은 관찰할 수 없다. 조립 라인 병목 연구의 중요한 부분이 빠진다.

## 재검토 조건

- 미공개 환경 C 나 후속 실험에서 재고·버퍼가 필수로 드러날 때 (코어 확장 + 결정 기록)
