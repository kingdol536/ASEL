# AI 사용 범위와 판단 근거 기록

> 포트폴리오 패키지 요구(docs/09 §5): "AI 사용 범위와 본인 판단 근거". 이 프로젝트에서 AI 는 두 가지로 쓰였다.
> 둘을 섞어 쓰지 않는다.

## 1. 개발 도구로서의 AI (Claude Code)

| 항목 | 내용 |
|---|---|
| 도구 | Claude Code (Anthropic, Opus 계열 모델) |
| 한 일 | 문서 분석, 설계안 제시, 코드·테스트·문서 작성, 실험 실행, 코드 리뷰, 보고서 초안 |
| 하지 않은 일 | 프로젝트 방향·범위·예산·실험 승인 결정 (아래 §3 의 사람 결정), API 키 취급(값을 읽거나 기록하지 않음) |
| 검증 방식 | 자동 테스트(불변조건·재현성·정답 누출), 사전 고정 실험 계획, 바이트 단위 재현 검사, 단계마다 코드 리뷰 |
| 기록 | 커밋 메시지의 `Co-Authored-By: Claude`, PR 본문의 생성 표시, 티켓(GitHub Issues) |

AI 가 쓴 코드도 사람이 쓴 코드와 같은 게이트를 통과해야 병합했다: 테스트 통과, 재현성, CI(Windows·Ubuntu, OS 간 결정성 비교).

## 2. 시뮬레이션 안의 AI (실험 대상)

| 항목 | 내용 |
|---|---|
| 모델 | Claude Haiku 5.5 (기본), Claude Sonnet 5.5 (EXP-003 파일럿·탐색 실행만 — 본 실험 팔은 표본 규칙상 0회) |
| 역할 | 배정 정책(작업→셀), 구조 제어 정책(셀 역할 전환) — 둘 다 **제안만** 하고 검증기가 수락/거절한다 |
| 정보 경계 | 공개 관측과 허용 후보만 받는다. 실제 처리 시간·고장 원인·채점식·요청 시간 제한은 받지 않는다(테스트로 확인) |
| 예산 | 상한 $55 (예약→정산 장부, 저장소 밖), 응답은 캐시해 재생 시 API 호출 0. 누적 $45.49 (2026-11-11, 장부 추정) |
| 결과 | EXP-001: 안전·유효, FIFO 와 비슷. EXP-003: 구조 제어는 조립 라인에서 이득, IT 서비스에서 실패. 배정은 비용 대비 이득 없음 |
| 결정 기록 | [결정 0004](decisions/0004-claude-policy-model-and-budget.md), 실험 계획 EXP-001·EXP-003, [EXP-003 보고서](../experiments/reports/EXP-003.md) |

시뮬레이션 안 AI 의 최종 역할·권한 구성은 여전히 **미결정**(R-06)이다. 실험 결과는 그 후보에 대한 증거일 뿐이다.

| 2026-11-11 | 다음 순서: EXP-003 보고서 → M6 마무리·병합 → 3D 그래픽 재생, 티켓 초안 검토 후 등록 | 남은 작업은 API 비용 없이 진행 |
| 2026-11-12 | 원자료·응답 캐시를 공개 Release `data-v1` 로 업로드 승인 | 파일 목록·크기·공개 전 검사 결과를 보고 결정 |

AI 가 제안했지만 사람이 아직 승인하지 않은 것: M4/EXP-002 결과, 결정 0005·0006 의 확정, EXP-003 결과 검토.

## 4. 한계

- 코드 대부분을 AI 가 작성했다. 사람의 기여는 방향·범위·우선순위 결정, 승인, 결과 검토다.
- AI 리뷰는 같은 계열 모델이 수행했다(별도 세션의 비평 포함). 다른 모델(Codex 등)에 의한 교차 검증은 이 환경 제약으로 제한적이다.
- **AI 판단이 사람의 의도와 어긋난 사례 (2026-11-11):** 개발 도구 AI 가 EXP-003 표본 규칙을 "남은 예산을 최대한 채운다"로 설계하고,
  실행 전 보고에 팔별 금액을 적지 않았다. 일반 승인("팍팍 써라")을 하루 소진 허락으로 해석했다. 결과는 오염되지 않았지만(예산 부족 대체 0)
  사람의 크레딧 사용 계획이 깨졌다. 이후 규칙: 유료 실행 전 팔별 금액 표 승인, 소진형 배분 금지, 탐색 실행 별도 승인
  ([결정 0004 사후 기록](decisions/0004-claude-policy-model-and-budget.md), [EXP-003 §8](../experiments/reports/EXP-003.md)).
