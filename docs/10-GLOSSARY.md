# 10. 용어 및 개념 사전

> 상태: **현재 작업 용어집**. 외부 표준 정의와 프로젝트 내부의 작업 정의를 구분한다.

## 1. 표기 규칙

- **공식/학술 개념:** 해당 연구 분야에서 널리 쓰이는 용례를 가능한 한 유지.
- **프로젝트 작업 정의:** 본 연구에서 측정·구현을 위해 좁게 설정한 의미. 일반적으로 통일된 정의라 주장하지 않음.
- 사용되는 의미가 다르면 문서에서 정의를 먼저 확인한다.

## 2. 연구 비전과 시스템

| 용어 | 영어 | 의미·구분 | 초기 적용 예시 |
|---|---|---|---|
| AX | AI Transformation | AI를 통한 업무·운영·조직·시스템 전환 | 작업을 AI에게 시키는 것뿐 아니라 구조 변경 검토 |
| 공진화 | Co-evolution | **작업 정의:** 환경, 구조, 통제 규칙이 상호 영향을 주며 변화 | 경로 변경이 조정 비용을 유발하고 정책 변경이 뒤따름 |
| 자기 적응 | Self-adaptation | 관측된 변화에 따라 실행·구성을 조정 | 수요 변화에 따른 작업 셀 전환 |
| 재구성 | Reconfiguration | 설비·서비스의 배치/기능/연결/정책 변경 | 포장 셀의 기능 변경 |
| 구조 | Architecture/Topology | 개체 구성과 관계·책임·계약 | 작업 셀-자원-경로 그래프 |
| 모듈 | Module | 명시된 인터페이스를 갖는 독립 단위 | 피킹 셀, 작업 스케줄러 |
| 이식성 | Portability | 다른 환경에 옮겼을 때 유지되는 기능·비용 | 코어 변경 없이 어댑터 추가 |
| 상호운용성 | Interoperability | 서로 다른 시스템 사이에서 의미 있는 교환 | 표준화된 상태/행동 스키마 |
| 통제 복잡성 | Control Complexity | **작업 정의(미확정 지표):** 관측·판단·조정·검증 부담 | 충돌 처리·결정 지연·개입 필요량 |
| 공통 언어 | Common Language (v0) | **작업 정의:** 엔진이 실제로 쓰는 개념(부품)과 관계의 목록. 코드에서 자동 생성 — `docs/11-COMMON-LANGUAGE.md`. 범용 온톨로지는 장기 후보(R-15) | 개체·자원·작업·역할·선행관계 |
| 부품 | Building Block | **작업 정의:** 공통 언어의 개념 하나. 산업 현장은 부품을 조립한 시나리오로 표현한다 | 작업 셀 = Entity + Resource + capability |
| 작업 비우기 | Draining | 재구성 요청 뒤 새 작업을 받지 않고 진행 작업이 끝나기를 기다리는 상태 (결정 0005) | 공용 셀 pick→pack 전환 요청 |
| 역할 전환 | Changeover | 셀이 멈춘 채 역할을 바꾸는 구간 (`changeover_s`) | 120s 동안 정지 후 pack |
| 구조 제어 주체 | Structure Controller | 재구성만 요청할 수 있는 결정 주체. 배정 주체와 분리 (결정 0006, 잠정) | P0/P1/P2 |

## 3. AI와 정보 접근

| 용어 | 영어 | 의미·구분 |
|---|---|---|
| 에이전트 | Agent | 관측에 따라 행동을 선택하는 주체. 반드시 LLM일 필요 없음 |
| 역할 | Role | 책임·관측·행동의 기능 묶음. 최종 역할 구조 미결정 |
| 권한 | Permission/Capability | 특정 정보·도구·행동에 대한 접근 허가. 최종 할당 미결정 |
| 관측 | Observation | 주체가 알 수 있는 상태 일부. 참값과 다를 수 있음 |
| 숨겨진 참값 | Ground Truth | 시뮬레이터가 알고 있는 실제 상태. 내부 정책에 누출 금지 |
| 정책 | Policy | 관측/상태에서 행동을 결정하는 규칙·함수 |
| 오케스트레이션 | Orchestration | 주체/도구의 호출·협력·순서·에러 관리 |
| 부분 관측 | Partial Observability | 행동 주체가 전체 상태를 직접 알지 못하는 조건 |
| 정책-실행 분리 | Policy/Actuation Separation | AI는 제안하고 검증된 요청만 환경에 적용 |

## 4. 세계 모델과 물리

| 용어 | 영어 | 의미·구분 |
|---|---|---|
| 이산 사건 시뮬레이션 | Discrete-event Simulation | 사건 발생 시각을 중심으로 상태를 갱신 |
| 2D 단위 실험 | 2D Unit Experiment | 낮은 공간 차원에서 개별 구조·관계·정책을 검사 |
| 3D 통합 시뮬레이션 | 3D Integrated Simulation | 3차원 공간/물리 제약 속에서 여러 기능 상호작용 확인 |
| 물리 엔진 | Physics Engine | 운동·충돌 등 물리 상태를 계산하는 엔진 |
| 다중 물리 | Multiphysics | 역학·열 등 서로 다른 물리 현상의 결합 |
| 모델 충실도 | Model Fidelity | 목적 현상의 상세·정확한 표현 정도. 고비용 고정밀이 항상 최선은 아님 |
| 모델 유효 범위 | Validity Domain | 특정 모델의 가정이 성립하는 조건 |
| 모델 정합성 | Consistency | 모델 간 단위·가정·시간·상태의 호환성 |
| Headless 실행 | Headless Execution | 그래픽 없이 시뮬레이션을 실행 |
| 디지털 트윈 | Digital Twin | 현실 대상과 상태/데이터가 연결된 디지털 표현. 단순 합성 세계와 구분 |
| Sim-to-Real Gap | Sim-to-Real Gap | 시뮬레이션과 현실 조건 차이에서 생기는 성능 간극 |

## 5. 수학과 최적화

| 용어 | 영어 | 의미·프로젝트 적용 |
|---|---|---|
| 그래프 | Graph | 노드/간선으로 개체·관계를 표현 |
| DSM | Design Structure Matrix | 구성요소 간 의존성을 행렬로 표현해 설계/모듈화를 분석 |
| 제약 최적화 | Constraint Optimization | 허용된 구조·행동 중 목적함수에 적합한 해 탐색 |
| CP-SAT | Constraint Programming SAT | 이산 제약·스케줄링 등에 사용하는 솔버 접근 |
| 강건 최적화 | Robust Optimization | 불확실성에 대한 최악/보수적 상황 고려 |
| 다목적 최적화 | Multi-objective Optimization | 여러 상충 목표 사이의 선택과 절충 분석 |
| 파레토 최적 | Pareto Optimal | 다른 목적을 악화시키지 않고는 개선 불가능한 해 |
| 히스테리시스 | Hysteresis | 상태 전환 기준을 다르게 두어 반복 스위칭 억제 |
| 최소 유지시간 | Minimum Dwell Time | 구조/정책 변경 후 일정 시간 유지하는 규칙 |
| MPC | Model Predictive Control | 예측 구간을 반복 최적화해 제어 행동 선택 |
| MDP/POMDP | Markov/Partially Observable MDP | 순차 의사결정, 부분 관측과 불확실성을 다루는 모델 |
| 정보가치 | Value of Information | 추가 관측/정밀화가 의사결정에 주는 기대 이익 |
| 불변조건 | Invariant | 지정된 모든 상태에서 유지되어야 할 조건 |

## 6. 평가·실험

| 용어 | 영어 | 의미·구분 |
|---|---|---|
| 검증 | Verification | 구현이 명세된 규칙대로 동작하는지 검사 |
| 타당성 평가 | Validation | 모형이 목적한 현상을 적절히 나타내는지 확인 |
| 평가기 | Evaluator | 관측·정답·결과를 비교하는 독립 구성요소 |
| 기준선 | Baseline | 효과를 판단하기 위한 비교 정책/설정 |
| 대응 실험 | Paired Experiment | 같은 외부 조건/시드로 정책 차이를 비교 |
| 절제 실험 | Ablation Study | 기능을 제거해 효과의 원인을 분석 |
| 미관측 시나리오 | Held-out Scenario | 정책 개발·조정에 사용하지 않은 최종 평가 조건 |
| 분포 이동 | Distribution Shift | 개발 당시와 실제 적용 시의 데이터 분포 차이 |
| 병목 전이 | Bottleneck Shift | 기존 제약의 완화와 함께 다른 제약이 지배적으로 되는 현상 |
| 인과 추론 | Causal Inference | 단순 상관이 아니라 개입의 효과를 판정하려는 접근 |
| 재현성 | Reproducibility | 명시된 설정·코드·시드로 결과를 다시 계산할 수 있는 정도 |

## 7. 혼동하기 쉬운 개념

- **에이전트 수 증가 ≠ 통제 향상.** 통신·조정 비용을 함께 본다.
- **시뮬레이터 성능 ≠ 정책의 품질.** 렌더링/계산 속도는 별도 결과다.
- **2D 성공 ≠ 3D 물리 성공.** 3D에는 새로운 공간·충돌·동역학 제약이 추가된다.
- **공통 인터페이스 ≠ 모든 산업에 무설정 적용.** 도메인별 어댑터·모델은 필요할 수 있다.
- **검증기 통과 ≠ 현실 세계 안전 보장.** 모델의 미반영 위험이 남는다.
- **코드 생성 도구 Claude Code ≠ 세계 내부 AI 에이전트.** 서로 역할이 다르다.
- **공진화 ≠ 기능 목록 증가.** 해결책으로 인해 발생한 후속 변화를 근거와 함께 보여야 한다.

## 8. 문서 상태와 용어 변경

- 새 연구 용어는 최초 등장 문서에서 작업 정의를 밝히고 이 문서에 추가한다.
- 수학적 수식/지표와 자연어 의미가 어긋나면 용어 대신 모델/실험 정의를 함께 수정한다.
- '통제 가능성', '적응성', '이식성', '안정성'은 현재 **후보 평가 차원**이며 최종 성공 지표로 확정되지 않았다.
