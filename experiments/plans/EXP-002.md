## 1. 질문

셀 역할 전환(구조 재구성)은 **어떤 수요 급증·전환 비용 조건에서** 고정 구조보다 나은가, 어디서 오히려 나빠지는가?
그리고 재구성은 병목을 **다른 곳으로 옮기는가**?

docs/06 §8 의 통과 조건을 따른다: "반드시 어느 정책이 우월함"이 아니라 **결과가 뒤집히는 조건을 재현 가능하게 보이는 것**.

## 2. 가설과 반증 조건

비교는 모두 같은 시나리오·시드끼리의 **대응 차이**(처리 − 기준)이며 주 지표는 주문 처리 시간 평균(s, 작을수록 좋음).

| ID | 가설 | 반증 조건 |
|---|---|---|
| H1 | 전환이 싼 조건(30s)에서 급증 ≥2배면 P1 이 P0 보다 처리 시간이 짧다 | 급증 2배·3배 × 전환 30s 에서 (P1−P0) 신뢰구간이 0 미만이 아님 |
| H2 (뒤집힘) | 전환 시간이 길어질수록 P1 의 이득이 줄고, 전환 300s 에서는 적어도 한 급증 수준에서 P1 이 P0 보다 나빠진다 | 모든 급증 수준에서 전환 300s 의 (P1−P0) 신뢰구간이 0 초과가 아니고, 30s→300s 로 차이가 커지는 경향도 없음 |
| H3 (비용 고려) | 전환 300s 에서 P2 는 P1 보다 전환을 적게 하고 처리 시간이 길지 않다 | 전환 300s 의 (P2−P1) 전환 횟수 차이 신뢰구간이 0 미만이 아님, 또는 처리 시간 차이 신뢰구간이 0 초과 |
| H4 (병목 이동) | 급증 ≥2배에서 P1 은 P0 보다 병목 이동이 많다 (pack 완화 → pick 병목) | 급증 2·3배 전 셀에서 (P1−P0) 병목 이동 횟수 신뢰구간이 0 초과가 아님 |

H2·H4 는 docs/07 §6 공진화 연쇄(수요 변화 → 병목 → 구조 변경 → 전환 비용·새 병목)의 검증이다. 발생하지 않으면 부정적 결과로 그대로 보고한다.

## 3. 실험 조건

- **시나리오 격자** (9개): 급증 배율 {1.5, 2, 3} × 전환 시간 {30, 120, 300}s.
  생성기 `experiments/configs/exp002_grid.py`, 결과 파일 `scenarios/exp002/*.yaml` (이 커밋에 고정).
  기본은 개발 시나리오 `warehouse-reconfig-dev` 와 같다(공용 셀 1개 pick↔pack, 급증 1200~2400s). 모든 수치는 가상 값.
- **정책** (구조 제어만 바꾼다, 배정은 FIFO 고정):
  - P0 고정 / P1 threshold 8.0 / P2 threshold 3.0, cost_per_min 2.0, min_dwell 300s
  - 기준값은 개발 시드 0~9, 전환 120s 개발 시나리오로만 조정했다 ([조정 기록](../reports/assets/M4/dev-tuning.md)).
    **조정 예산이 다르다**: P1 후보 11개, P2 조합 27개. 평가 시드로는 조정하지 않는다.
- **시드**: 평가용 200~229 (30개, 임시). 개발 시드(0~9), EXP-001 시드(0~1, 100~129)와 겹치지 않는다.
- 실행 수: 9 × 3 × 30 = 810회. 비용 0 (API 호출 없음).
- 평가기: `eval-0.3` (병목 지표 포함, 공개 로그만).

| 지표 | 역할 | 비고 |

| 주문 처리 시간 평균 `flow_mean_s` | 주 지표 (H1·H2·H3) | 완료 주문만. 완료율과 함께 본다 |
| 처리 시간 P95 `flow_p95_s` | 보조 | |

| 전환 완료 수 `reconf_completed` | H3 | |

## 5. 분석 계획 (사전 고정)

- 각 격자 셀(시나리오)마다 대응 차이 (P1−P0), (P2−P0), (P2−P1) 를 시드별로 계산.
- 평균 차이와 부트스트랩 95% 신뢰구간 (재표본 10,000회, 고정 시드 20261111) — `asel compare --column structure`.
- 신뢰구간이 0 을 포함하지 않을 때만 "차이 있음"으로 쓴다. 뒤집힘 조건 = 같은 비교에서 신뢰구간 부호가 격자 안에서 바뀌는 지점.
- 시드별 분포와 최악 사례를 같이 공개한다.
- 9개 셀 × 3비교 × 여러 지표라 **다중 비교** 문제가 있다. 사전 가설(H1~H4)에 해당하는 비교만 확증적으로 해석하고 나머지는 탐색적으로 표시한다.

## 6. 한계 (미리 밝힘)

- 환경 A 하나, 재구성 가능한 셀 1개, 배정 FIFO 고정, 결정 0005(비우고 전환)·0006(구조→배정 순서)에 의존.
- 기준값은 전환 120s 에서만 조정했다 → 30s·300s 에서 P1 이 불리할 수 있다. 이것이 H2·H3 가 보려는 현상이기도 하므로, 해석할 때 "조정 조건 밖 성능"임을 명시한다.
- 처리 시간 분포·수치는 모두 가상이다. 현실 공정 성능을 뜻하지 않는다.
