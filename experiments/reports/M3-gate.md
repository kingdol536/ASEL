## 4. 사고 기록 (실패도 남긴다)

- **본 실험 1차 실행 중단:** 6병렬 기록 중 Windows 에서 지우는 중인 예산 장부 잠금 파일을 만들려다 `PermissionError` 가 나 배치가 중단됐다(약 $1.1 지출 후).
  원인: 잠금 코드가 `FileExistsError` 만 '사용 중'으로 처리했다. 수정(`9dbce44`): `PermissionError` 도 대기·재시도, 장부 읽기·교체 재시도.
  회귀 테스트 2개(지우는 중 상태 흉내, 8프로세스 고경합)는 이전 코드에서 실패함을 확인했다.
- **재실행:** 같은 설정으로 처음부터 다시 실행. 1차에서 이미 받은 응답은 캐시에서 재사용(비용 없음, 같은 결과)했다. 그래서 이 배치의 실행별 비용 열은 실제 실행당 비용을 **과소** 표시한다 — 실제 비용은 장부 합계로 본다.
- 응답 캐시 경합(같은 요청 동시 기록)은 0건이었다.

## 5. 남은 위험

- 환경 A 의 결정 공간이 좁아 이 실험은 Claude 의 '판단력'을 거의 시험하지 못했다. 안전 경계·운영 가능성 확인이 주된 성과다.
- 캐시된 응답은 2026-11-11 의 `claude-haiku-5-5` 출력이다. 모델이 바뀌면 재생과 재측정을 구분해야 한다(`served_models` 기록).
- 시드 30개는 임시 값이었다. 차이가 매우 작아 표본을 늘려도 실질 결론은 바뀌지 않을 가능성이 높다(가설).
- 관측(프롬프트) 크기는 급증 시 커진다 (리뷰 보류 항목). 이번 실험에서는 비용·대체 문제로 이어지지 않았다.
