### 3.2 사전 가설 판정 (대응 차이, 부트스트랩 95% CI)

| 가설 | 판정 | 근거 |
|---|---|---|
| H1 전환이 싸면(30s) 급증 ≥2배에서 P1 < P0 | **지지** | 2배 −105s [−124, −86], 3배 −29s [−52, −7] |
| H2 전환이 비쌀수록 P1 이득 감소, 300s 에서 뒤집힘 | **부분 지지 — 뒤집힘은 관측 안 됨** | 이득은 모든 급증 수준에서 전환 시간에 따라 줄었다 (2배: −105 → −87 → −57s, 3배: −29 → −14 → **+2s [−11, +15]**). 3배·300s 에서 이득이 사라졌지만 P1 이 P0 보다 **유의하게 나빠진 셀은 없다**. P95 기준으로는 모든 셀에서 P1 이 여전히 낫다 |
| H3 전환 300s 에서 P2 가 P1 보다 전환이 적고 처리 시간이 길지 않음 | **지지** | 전환 횟수 차 1.5배 −0.53, 2배 −0.87, 3배 −1.43 (모두 CI < 0). 처리 시간 차 +3.6 / −7.7 / −8.3s (모두 CI 가 0 포함 = 길지 않음). 3배·300s 의 P95 는 P2 가 88s 짧음 [−129, −47] |
| H4 급증 ≥2배에서 P1 의 병목 이동이 P0 보다 많음 | **지지** | 6개 셀 모두 +1.7 ~ +2.3회, CI > 0 |

**계획서의 결함(사후 발견):** H2 의 반증 조건을 "모든 300s 셀에서 악화가 없고 **동시에** 경향도 없을 때"로 썼다.
그래서 이번 결과(경향은 있음, 뒤집힘은 없음)는 형식상 반증되지 않지만, 가설 문장의 핵심("뒤집힌다")은 확인되지 않았다.
판정은 가설 문장 기준으로 "부분 지지"라고 쓴다. 다음 계획서에서는 반증 조건을 가설 문장과 일치시켜야 한다.

| 시나리오 | 정책 | pack→pick 이동이 있었던 실행 비율 | 평균 부하 pick / pack |
|---|---|---|---|
| 2배 · 120s | P0 | 0.23 | 1.33 / **9.14** |

| 3배 · 120s | P0 | 0.37 | 4.54 / **14.13** |

고정 구조에서는 포장(pack)이 계속 병목이다. 공용 셀을 포장으로 돌리면 포장 부하가 절반 정도로 줄지만, **피킹(pick) 부하가 두 배가 되어 병목이 피킹으로 옮겨 간다**.
docs/07 §6 의 연쇄(수요 변화 → 기존 병목 → 구조 변경 → 전환 비용·새 병목)가 데이터로 재현됐다.
뷰어 캡처: [개발 시나리오 P1](assets/M4/dev-p1-seed2-timeline.jpg), 재생 파일: [2배·120s P0](assets/M4/view-s2-c120-p0-seed200.html) / [P1](assets/M4/view-s2-c120-p1-seed200.html).

### 3.4 전환 비용

잃은 용량-초(비우는 시간 + 전환 시간)는 P1 이 전환 시간에 비례해 커진다 (3배: 317 → 617 → 943s). P2 는 전환이 비쌀수록 덜 전환해 300s 에서 P1 의 약 절반(497s)이다.
P2 는 전환이 싼 30s 에서는 P1 보다 **더 자주** 전환한다(기준값이 전환 시간에 비례해 낮아지므로). 설계대로의 동작이며, 1.5배·30s 에서는 처리 시간 이득이 거의 없다(−4.8s, CI 0 포함).

## 4. 남은 위험

- **결과는 사용자 승인 전 잠정.** 계획서의 H2 반증 조건 결함을 위에 명시했다.
- 기준값을 전환 120s 에서만 조정했다 → 30s·300s 결과에는 '조정 조건 밖' 효과가 섞여 있다.
- 조정 예산이 다르다 (P1 후보 11개, P2 조합 27개).
- 환경 하나, 재구성 셀 하나, 배정 FIFO 고정, 결정 0005·0006 에 의존. 9셀 × 다지표의 다중 비교 — H1~H4 외 차이는 탐색적.
- 병목 지표의 분모 하한 1 은 docs/06 정의에서 벗어난 구현 선택이다 (가용 0 시간은 따로 보고).
- 처리 시간 평균은 완료 주문만 센다. P0 는 완료율이 낮아(3배: 0.708) 평균이 **유리하게** 나올 수 있다 — 그래도 P0 가 가장 나빴다.
