### 3.3 원자료 공개 (#51)

- 공개 전 검사: `experiments/batches` 와 응답 캐시 89,079개 파일(3.45 GB)에서 API 키 형식·사용자 경로·이메일 **0건**. 일부러 넣은 가짜 키·경로·이메일 3건은 모두 잡았다(양성 대조).
- 응답 캐시에는 응답 텍스트·모델 이름·사용량·지연 시간만 있다 (요청·키 없음).
- 공개 파일 5개, 합계 약 232 MB ([체크섬](assets/data-v1/SHA256SUMS.txt)):

| 파일 | 크기 | 내용 |

| `batches-EXP-001-pilot.zip` | 0.8 MB | EXP-001 파일럿 |
| `batches-EXP-002.zip` | 41.7 MB | EXP-002 810회 |

- 알려진 결함: 평가기 0.6 이전에는 `evaluation.json` 의 `experiment` 필드가 항상 `EXP-001` 이었다(리뷰에서 발견, 고침). EXP-003 은 같은 평가기로 다시 평가해 바로잡았고(평가표는 바이트 동일), EXP-001·002 는 보고서 수치의 근거를 바꾸지 않도록 당시 평가 결과를 그대로 둔다. 실험 구분은 폴더 이름과 manifest 의 `extra.experiment` 를 쓴다.

## 4. 남은 위험

- **사용자 승인 대기:** M4/EXP-002 결과, 결정 0005·0006 확정, EXP-003 결과 검토. 승인 전까지 해당 결과는 잠정이다.
- 3D 그래픽 시연이 아직 없다. 엔진 판정은 있으므로 화면은 그 판정을 보여주는 재생기로 만든다 (#57~#59).
- 환경 3개, 재구성 셀 각 1개, 프롬프트 각 하나. 결과를 산업 일반으로 확장해 해석하지 않는다.
- 외부 사람이 실제로 받아서 돌려 본 적은 없다. 깨끗한 clone 시험은 같은 PC 에서 했다.
- 시뮬레이션 안 AI 의 최종 역할·권한 구성과 최종 평가 지표는 미결정이다.
- API 예산: 장부 누적 $45.49 / $55. 남은 작업은 API 비용 0 으로 계획했다.
